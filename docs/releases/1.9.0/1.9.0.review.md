# PR Review: #1 — ParallaxStyle 1.9.0

**Reviewed**: 2026-11-06
**Branch**: release/v1.9.0 → main
**Command**: `/ecc:code-review` (PR mode), diff completo e file letti per intero
**Decision**: APPROVE dopo le correzioni (tutti i finding risolti nel commit `3a5866c`)

## Summary

La PR porta test, correzioni audio, interfaccia nuova, flusso di release e build per
Anagram. La review ha trovato funzioni e file troppo lunghi nel percorso audio, due
difetti di comportamento nell'interfaccia e due fragilità della CI; nessun problema di
sicurezza nel codice del plugin.

## Findings

### CRITICAL
Nessuno.

### HIGH
- **Funzioni e file troppo lunghi** — `src/PluginProcessor.cpp`: `processChunk` di 299
  righe, file di 988 righe; anche il costruttore dell'editor (136 righe) e
  `SpectrumView::paint` erano lunghi. **Corretto**: percorso audio in
  `src/ProcessorAudio.cpp` (`advanceRamps`, `applyGate`, `processLowBand`,
  `processMidBand`, `processHighBand`, `sumBandsAndMaster`, `mixBypass`), editor e
  spettro divisi in funzioni di disegno e di montaggio. Uscita ancora bit-identica.

### MEDIUM
- **Banda MID rovesciabile** — `src/SpectrumView.cpp`, `dragTo`: trascinando TO sotto
  FROM le maniglie si incrociavano e la banda appariva vuota. **Corretto** con un limite
  sul trascinamento; test `TheMidBandCannotBeDraggedInsideOut`.
- **Spettro spento da un secondo editor** — `src/PluginProcessor.h`: un solo flag per i tap
  dell'analizzatore; con l'editor aperto due volte, chiuderne uno fermava l'altro.
  **Corretto** contando gli editor aperti; test `StaysOnWhileAnyEditorIsOpen`.
- **pluginval senza verifica d'integrità** — `.github/workflows/build.yml`: lo zip
  scaricato veniva eseguito senza controllo. **Corretto** con lo SHA-256 fisso per ogni
  sistema.
- **Discovery dei test senza display** — `tests/CMakeLists.txt`: `gtest_discover_tests`
  avviava i programmi di test, che aprono un contesto grafico JUCE, durante la build.
  **Corretto** con `DISCOVERY_MODE PRE_TEST` (elenco al momento di CTest, sotto xvfb).

### LOW
- **`const_cast` in `anySmoothing`** — **Corretto** con una versione const di
  `forEachSmoother`.
